# t3code-claude-theme

Claude dark and light UI themes for [T3 Code](https://github.com/pingdotgg/t3code).

## files

- `claude-dark.json`: Claude dark theme with charcoal background and warm coral accents.
- `claude-light.json`: Claude light theme with warm ivory background and terracotta accents.

## usage

Import or apply the theme JSON configuration within T3 Code UI / theme settings.
