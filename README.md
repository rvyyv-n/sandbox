# side-quests

Small one-off projects and tasks that don't deserve their own repo. Each one lives in its own folder with its own README.

| Project | What it is |
|---|---|
| [`t3code-icons`](t3code-icons) | Dark-mode replacement icons for T3 Code (SVG / PNG / ICO + generator script) |

## Conventions

- One folder per project, named in `kebab-case`.
- Each folder has a README covering what it is, how to use it and how to regenerate or run it.
- Keep outputs small and committed when they're the point (icons, images). Build junk stays out (see `.gitignore`).
